# 🚀 Getting Started

## Clone repository

```bash
git clone https://github.com/LeviusNhan/portfolio-react-ts.git
```

Go into project

```bash
cd portfolio-react-ts
```

Install packages

```bash
npm install
```

Run development server

```bash
npm run dev
```

Production build

```bash
npm run build
```

Preview production

```bash
npm run preview
```

---

# 🔐 Environment Variables

Create

```text
.env
```

Then add

```env
VITE_EMAILJS_SERVICE_ID=
VITE_EMAILJS_TEMPLATE_ID=
VITE_EMAILJS_PUBLIC_KEY=
```

You can get these values from

https://dashboard.emailjs.com
