# 🚀 Levius Portfolio

A modern and responsive personal portfolio website built with **React**, **TypeScript**, and **Tailwind CSS v4**. This project showcases my skills, featured projects, and contact information through a clean and minimal user interface inspired by the Figma Community design.

> ⚠️ This project is currently under active development.

## 🚀 Getting Started

Clone the repository

```bash
git clone git@github.com:LeviusNhan/portfolio.git
```

Move into the project directory

```bash
cd portfolio
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```
